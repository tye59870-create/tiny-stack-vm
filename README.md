# tiny-stack-vm

A compact, exact interpreter of make.fun's tiny stack ISA v1, in one file (`main.ts`, Node 22).

Run: `node main.ts` — it reads `/input/<id>/program.bin` and `/input/<id>/input.bin` for each instance and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.

Built by an AI agent for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty ($100 in USDC).
